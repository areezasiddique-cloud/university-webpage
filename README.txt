CRESCENT UNIVERSITY WEBSITE — ASSIGNMENT #01

FILES
- index.html: main website page
- style.css: page layout, colors, fonts, spacing, responsive styling and table/form styling
- script.js: mobile navigation, welcome button and demo form response
- images/campus.svg and images/library.svg: original vector illustrations
- website-screenshot.png and website-screenshot-admissions.png: screenshot-style previews

HOW TO OPEN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. Keep the images folder beside index.html so the illustrations load.

CUSTOMIZE BEFORE SUBMISSION
- Add your student name and student ID to your assignment cover page if required.
- Crescent University and the academic program details are fictional sample content; replace them if your instructor expects a real university.
- The form is a front-end demonstration only. It validates required fields and displays a confirmation; it does not send or store inquiries on a server.
- The PDF contains preview images. For final evidence, open the site in your browser and take your own screenshots after testing the buttons and form.
